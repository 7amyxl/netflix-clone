# 🎬 Netflix Clone

A fully responsive **Netflix Clone** built using modern web technologies to replicate the core features and UI of Netflix.  
This project demonstrates **frontend design, API integration**, and **authentication** skills.

---

## 🚀 Features

- 🎥 Browse trending movies & TV shows  
- 🔍 Search for movies  
- 🧠 Dynamic movie details with posters and trailers  
- ❤️ Add/remove favorites (watchlist)  
- 🔐 User authentication (Sign In / Sign Up)  
- 🌙 Dark modern Netflix-style UI  
- 📱 Fully responsive for all devices  

---

## 🧰 Tech Stack

**Frontend:**
- React.js / Next.js  
- HTML5, CSS3, JavaScript (ES6+)  
- Tailwind CSS / Styled Components  

**Backend:**
- Firebase / Node.js + Express (optional)  

**API:**
- TMDb (The Movie Database) API  

**Deployment:**
- Vercel / Netlify
